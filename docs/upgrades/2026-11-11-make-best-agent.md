# 송월 에이전트 업그레이드

make_best_agent의 제품 동작을 기존 송월 React·FastAPI 앱에 적용했다. MES·LOT·물류·문서 조회와 서버 키 관리, 접근 통제는 유지한다.

- LangGraph: 요청 분해 → 범위를 제한한 복수 조회 → 근거 종합 및 요청별 누락 검사. 근거와 답변 인용을 확인하지 못한 요청은 추가 확인으로 남긴다.
- 실제 MES 질문은 MES 도구만 사용한다. 샘플 문서와 LOT 기록은 MES 원본으로 표시하지 않는다.
- 사용자 발화에 나온 LOT로 후속 질문을 해석한다. 선택 LOT와 질문 LOT가 다르면 확인을 요청한다. LOT 변경과 새 대화는 화면 문맥을 초기화한다.
- 데이터·지식베이스·복합 추천 질문 각 10개, 호출명 불필요, 비교표 우선 표시, 답변 시작 위치 유지, 모바일 화면 적용.
- 음성도 같은 분석 도구를 사용한다. 발화 중단 시 조회 취소·오래된 답변 차단, 짧은 업무 요약, 마이크 정리와 재생 오류 안내를 적용한다.

## 검증

- v2 API·데이터·범위 테스트 49개 통과, TypeScript·Vite 빌드 통과.
- 실제 AI/MES 질의: 생산 진행과 포장 완료 비교. LangGraph 실행, MES 조회 3종, 비교표 3개와 요청별 검사 반환 확인.
- Chrome 1440px·390px 화면: 가로 넘침과 페이지 JavaScript 오류 없음. 긴 답변 상세를 펼쳐도 끝으로 자동 이동하지 않음.
- `browser-voice-upgrade.cjs`: 연결 실패 시 마이크 해제, 호출명 없는 발화, 느린 조회 도중 끼어들기, 늦은 답변 격리, 음소거와 종료 검증. WebRTC 모사 테스트이며 실제 마이크 음질 검증은 별도다.

## 실행

프로젝트 루트에서 `SONGWOL_DB_PATH=data/songwol_mes.db .venv-v2/bin/python -m uvicorn v2.api:app --host 127.0.0.1 --port 8516`.

외부 서버 배포와 Git push는 이번 변경에 포함하지 않았다. API 키가 없으면 기존 결정적 자료 조회를 제공하며 AI 비교 판단 완료로 표시하지 않는다. 누락 검사는 보수적인 확인 표시이며 자동 재조회·정답 보증은 아니다.
