# 원단·인쇄 LOT 추적 SOP (RAG 검증용 예시)

- 문서번호: SOP-LOT-R2
- 상태: 미승인 · RAG 검증용 샘플 (실제 제조 승인 문서 아님)

원부자재 입고 시 원단 LOT, 공급처, 입고일, 수량, 흡수율·강도 검사결과를 등록한다. 작업지시가 발행되면 주문번호와 원단 LOT를 연결하고, 인쇄 시작 시 고유 인쇄 LOT를 생성한다. 생산수량·불량수량·인쇄조건·검사결과·포장 LOT·출하번호는 인쇄 LOT를 중심으로 연결한다.

클레임이 발생하면 출하번호 → 주문번호 → 인쇄 LOT → 작업지시 → 원단 LOT → 품질·공정조건 순으로 역추적한다. 누락된 연결은 추정으로 채우지 않고 데이터 보완 대상으로 남긴다.
