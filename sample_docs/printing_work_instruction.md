# 인쇄 작업 전·후 기록 절차 (RAG 검증용 예시)

- 문서번호: WI-PRINT-R1
- 상태: 미승인 · 검증용 샘플 (실제 제조 승인 문서 아님)
- 적용: 나염·승화·전사 인쇄 작업

작업 전에는 작업지시, 품목코드, 승인 도안과 원단 LOT를 대조한다. 인쇄 시작 시 인쇄 LOT를 부여하고 작업자, 설비, 시작시각, 인쇄방법 및 작업조건의 값과 단위를 기록한다.

작업 후에는 계획수량, 양품수량, 불량수량, 종료시각과 특이사항을 남긴다. 공정조건은 합격 기준으로 추정하지 말고 검사 기록 및 승인된 품목 기준과 함께 담당자가 검토한다.
