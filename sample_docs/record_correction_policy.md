# 제조 기록 정정·개정 이력 가이드 (RAG 검증용 예시)

- 문서번호: DOC-RECORD-R1
- 상태: 미승인 · 검증용 샘플 (실제 제조 승인 문서 아님)
- 적용: 수기·시트 기반 제조 기록의 보완

기존 기록을 조용히 덮어쓰지 않는다. 정정 시 원래 값, 변경 값, 사유, 변경자, 확인시각과 근거 자료를 보존한다. 주문번호·품목코드·원단 LOT·인쇄 LOT의 연결이 모호하면 근거 없이 연계하지 않고 미확인으로 남긴다.

문서 개정은 문서번호, 개정번호, 작성자, 검토·승인 상태와 적용일로 관리한다. 미승인 문서를 운영 기준으로 사용하지 않는다.
