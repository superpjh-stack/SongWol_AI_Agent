# 주문·작업지시 연결 가이드 (RAG 검증용 예시)

- 문서번호: SOP-ORDER-R1
- 상태: 미승인 · 검증용 샘플 (실제 제조 승인 문서 아님)
- 적용: 수주 등록부터 작업지시 연결까지

수주 기록은 주문번호, 고객, 품목코드, 주문수량, 납기, 진행상태와 우선순위를 함께 확인한다. 작업지시를 만들 때 주문번호와 품목코드가 수주 기록과 같은지 대조하고 계획수량과 작업단위를 기록한다.

납기 또는 주문 내용이 바뀌면 변경자, 확인시각, 원본 요청을 함께 남긴다. Agent는 일정 변경이나 작업지시 발행을 대신 결정하지 않는다.
