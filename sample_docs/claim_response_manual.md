# 클레임 대응 매뉴얼 (RAG 검증용 예시)

- 문서번호: CS-CLAIM-R4
- 상태: 미승인 · RAG 검증용 샘플 (실제 제조 승인 문서 아님)

색상 클레임은 고객 주문, 승인 시안, 인쇄 LOT, 원단 LOT, ΔE 측정, 인쇄 온도·압력·잉크량·라인속도, 작업자와 출하 이력을 확인한다. 포장 클레임은 포장단위, 라벨, 스캔, 검사자와 출하수량을 대조한다.

Agent는 관련 이력을 모아 원인 후보와 누락 증빙을 제시할 수 있지만, 귀책·보상·종결을 결정하지 않는다. 품질 담당자가 원인을 확인하고 영업 책임자가 고객 대응안을 승인한다. 재발방지는 SOP와 품목 기준정보의 개정번호로 관리한다.
