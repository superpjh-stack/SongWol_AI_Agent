# 인쇄 품질 기준서 (RAG 검증용 예시)

- 문서번호: QC-PRINT-R3
- 상태: 미승인 · RAG 검증용 샘플 (실제 제조 승인 문서 아님)
- 적용: 나염·승화 인쇄 LOT

검사는 승인 시안과 인쇄물을 비교해 색상, 번짐, 오염, 위치, 흡수율, 강도를 확인한다. 측정값에는 인쇄 LOT, 검사시각, 검사자, 장비, 단위와 기준서 개정번호를 남긴다.

ΔE 또는 외관 결과가 승인기준을 벗어나면 해당 인쇄 LOT를 품질보류하고 포장·출하 투입을 차단한다. 재검사 없이 Agent가 합격 또는 출하 가능으로 판정해서는 안 된다. 기준 수치와 측정 조건은 실제 승인 기준서로 교체해야 한다.
