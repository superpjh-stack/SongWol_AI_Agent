# 원단 입고·검사 체크리스트 (RAG 검증용 예시)

- 문서번호: QC-INCOMING-R1
- 상태: 미승인 · 검증용 샘플 (실제 제조 승인 문서 아님)
- 적용: 원단 입고 및 LOT 등록

입고 시 공급처, 품목, 수량과 원단 LOT 식별표를 대조하고 입고일·보관위치를 기록한다. 검사 기록에는 측정 항목, 값과 단위, 검사자, 장비, 확인시각과 적용 기준서 개정번호를 함께 남긴다.

판정 한계값은 실제 적용 중인 승인 기준서에서 확인한다. 정보가 없거나 기록 간 식별자가 맞지 않으면 임의로 판정하지 않고 담당자 확인 대상으로 둔다.
