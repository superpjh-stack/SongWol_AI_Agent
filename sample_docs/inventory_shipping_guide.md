# 재고·출하 운영 가이드 (RAG 검증용 예시)

- 문서번호: LOG-INV-R2
- 상태: 미승인 · RAG 검증용 샘플 (실제 제조 승인 문서 아님)

재고는 품목코드, 원단/인쇄 LOT, 위치, 수량, 단위, 최근 실사시각으로 관리한다. 안전재고 미달은 담당자에게 알리되 발주를 자동 실행하지 않는다. 수기 또는 구글시트 조정분은 조정사유·작업자·승인자와 원본 증빙을 보존한다.

출하 전 주문수량, 양품수량, 품질보류 여부, 포장단위, 라벨, 운송사를 확인한다. 품질보류 LOT와 출하 미승인 주문은 출하할 수 없다. 보류 해제와 출하 승인은 품질·물류 담당자가 수행한다.
